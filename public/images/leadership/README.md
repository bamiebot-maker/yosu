# YOSU Official Leadership Image Assets Guide

This directory holds the official high-resolution headshot photographs for the 2026/2027 Comdr Sobur-Led Administration.

## Image Standards
- **Dimensions**: Square 1:1 Aspect Ratio (e.g. 600px × 600px or 800px × 800px)
- **Format**: `.jpg`, `.jpeg`, `.png`, or `.webp`
- **Background**: Studio background, traditional attire, or official university backdrop
